# Principes du site

- **Contenu d'abord** : le site sert à trouver et citer vos travaux (publications filtrables, BibTeX, métadonnées scholarly pour Google Scholar).
- **Simple et durable** : site statique (Hugo), aucun serveur, aucune base de données, aucun traqueur.
- **Accessible** : navigation au clavier, contrastes élevés, thème clair forcé, respect de « réduire les animations », impression propre.
- **Bilingue-ready** : interface en français (fr-CA) ; fichier `i18n/en.yaml` prêt pour l'anglais.
- **Sobre** : palette océan, titres à empattement, texte système ; aucune dépendance externe à l'exécution.
- **Honnête** : les éléments rédigés ou devinés (bio, liens de co-auteurs, mots-clés) sont signalés pour relecture.
- **Réversible** : tout est du texte dans Git ; rien n'est publié sans validation.
